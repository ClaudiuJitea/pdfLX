# pdfLX

**0.3**

Ein übersichtlicher PDF-Arbeitsbereich für Linux. Bearbeiten Sie Text und Bilder, kommentieren Sie Dokumente, organisieren Sie Seiten und exportieren Sie Dateien.

```sh
python run-editor.py
```

```sh
pip install .
pdflx
```
